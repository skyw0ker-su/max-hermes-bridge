# Как создать бота в MAX и получить токен

Бот нужен один раз. Через него Hermes Agent будет получать ваши сообщения и отвечать в MAX.

## 1. Откройте раздел для ботов

Создавать ботов в MAX могут только организации, поэтому нужен кабинет MAX для бизнеса:

- https://business.max.ru/self — для самозанятых и ИП;
- или https://max.ru/business_bot — бот-помощник внутри MAX.

Войдите под своим аккаунтом MAX и пройдите проверку организации (для ИП и самозанятых это занимает несколько минут).

## 2. Создайте бота

1. В кабинете откройте раздел **«Чат-боты»**.
2. Нажмите **«Создать бота»**.
3. Укажите имя и описание. Имя будет видно в чатах.
4. Дождитесь модерации. Обычно она короткая.

## 3. Скопируйте токен

1. В разделе «Чат-боты» выберите своего бота.
2. Нажмите **⋮ → Настройки → «Токен»**.
3. Скопируйте токен.

## 4. Установите мост

Скачайте репозиторий (Code → Download ZIP), распакуйте и запустите `installer\install.cmd`.
Установщик спросит токен (ввод скрыт), проверит его, поставит плагин и попросит написать боту сообщение, чтобы узнать ваш `user_id`.

Вручную то же самое делается так:

```
MAX_BOT_TOKEN=<токен>
MAX_ALLOWED_USERS=<ваш user_id>
MAX_CA_BUNDLE=%LOCALAPPDATA%\hermes\max-ca\russian_trusted_ca_bundle.pem
```

Строки добавляются в `%LOCALAPPDATA%\hermes\.env`, затем:

```
hermes plugins enable max-platform
hermes gateway restart
```

## 5. Проверка

Найдите бота в MAX и напишите ему «привет». Ответ даёт Hermes Agent, пока он работает, у бота показывается «печатает…».

## Если не работает

| Симптом | Причина и решение |
| --- | --- |
| Установщик: «Токен не принят» | Токен скопирован с пробелом или устарел. Выпустите новый. |
| Ошибка сертификата TLS | MAX использует корень Минцифры. Установщик подкладывает его в `max-ca\` и прописывает `MAX_CA_BUNDLE`. Проверьте путь в `.env`. |
| Бот молчит | Ваш `user_id` не входит в `MAX_ALLOWED_USERS`. Проверьте `.env` и перезапустите шлюз. |
| «Another consumer» / бот отвечает дважды | С одним токеном работает второй мост. Остановите его: опрос MAX допускает одного потребителя. |
| Плагин не виден | Выполните `hermes plugins list` и проверьте, что `max-platform` включён. |

## Безопасность

- Токен даёт полный контроль над ботом. Не публикуйте его и не отправляйте в чат.
- Всегда задавайте `MAX_ALLOWED_USERS`: пустой список разрешает писать боту любому, а Hermes Agent умеет выполнять команды на вашем ПК.
- Файл `.env` не попадает в git (см. `.gitignore`).
- Если токен утёк, выпустите новый в настройках бота и обновите `.env`.
