# Мост мессенджера MAX для HERMES AGENT

Плагин платформы для [Hermes Agent](https://hermes-agent.nousresearch.com/docs): пишете боту в MAX (max.ru) и получаете ответ Hermes, как в Telegram. Работает с телефона и ПК, не требует публичного адреса: используется Long Polling.

## Возможности

- Обычный ход Hermes на каждое сообщение, ответ приходит в тот же чат.
- Индикатор «печатает…», отметка о прочтении.
- Картинки и файлы в обе стороны.
- Белый список пользователей (`MAX_ALLOWED_USERS`) и домашний канал для cron-уведомлений.
- Маркер опроса сохраняется на диск: после перезапуска шлюза старые сообщения не повторяются.
- Только `aiohttp`, который уже есть в Hermes. Ядро Hermes не изменяется.

## Установка

1. Создайте бота и получите токен: [docs/SETUP-BOT.md](docs/SETUP-BOT.md).
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите `installer\install.cmd`. Он:
   - спросит токен (ввод скрыт) и проверит его через API MAX;
   - скопирует плагин в `%LOCALAPPDATA%\hermes\plugins\max-platform`;
   - положит сертификат Минцифры и пропишет `MAX_CA_BUNDLE`;
   - узнает ваш `user_id` по первому сообщению боту и запишет белый список;
   - сохранит резервную копию `.env`, включит плагин и перезапустит шлюз.
4. Напишите боту в MAX.

Параметры: `install.ps1 -Token <токен> -UserId <id> -HermesHome <путь> -NoRestart`.

## Состав

```
max-platform/     плагин (adapter.py, plugin.yaml, тесты)
  certs/          корневой и подчинённый сертификаты Минцифры
installer/        install.cmd, install.ps1
docs/             SETUP-BOT.md: создание бота
```

Настройки плагина и таблица переменных окружения: [max-platform/README.md](max-platform/README.md).

## Требования

Windows 10/11, установленный Hermes Agent с рабочим шлюзом, аккаунт MAX с доступом к разделу «Чат-боты».

## Безопасность

Hermes Agent выполняет команды на вашем компьютере. Обязательно задайте `MAX_ALLOWED_USERS` (установщик делает это сам). Токен храните только в `.env`.
